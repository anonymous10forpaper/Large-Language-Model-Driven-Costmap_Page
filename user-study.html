01

Study map & task concepts

Waypoint (WP)
A destination or a stop to visit in a specified order.
Zone
A named region where access, traversal costs, or conditional rules apply.
Keepout
A rule that prevents the robot from entering a specified zone.
Zone cost
A value from 0 to 252. Higher values make a zone less preferred; a cost is not a keepout.
Person avoidance
Maintain the system's default safety distance from detected people.
Time condition
Apply a rule for a specified duration, starting now.
Event condition
Apply a different rule while an external signal, such as fire_alarm, is active.
02

Participant instructions

  1. Write one English natural-language command for each task. Include every requirement listed in the task brief.
  2. Use your own wording. There is no fixed sentence template. A command may contain one sentence or multiple clauses; do not write JSON or program syntax.
  3. You may ask about task meanings or map locations. Researchers will not suggest English wording or correct your sentences.
  4. Submit all commands before receiving model or GUI feedback. No example commands or policy JSON are provided during command writing.
